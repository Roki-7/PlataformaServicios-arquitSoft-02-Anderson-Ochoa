# Historias de usuario

## 1. Descripción

Las historias de usuario representan las principales necesidades de los usuarios de la plataforma desde su propia perspectiva.

Se utiliza la estructura:

**Como [actor], quiero [acción], para [beneficio].**

## 2. Historias de usuario

| ID | Actor | Historia de usuario |
|---|---|---|
| HU01 | Cliente | Como cliente, quiero registrarme e iniciar sesión, para utilizar las funciones de contratación de la plataforma. |
| HU02 | Prestador de servicios | Como prestador de servicios, quiero crear y actualizar mi perfil profesional, para mostrar mi experiencia, especialidades y disponibilidad. |
| HU03 | Prestador de servicios | Como prestador de servicios, quiero publicar y administrar los servicios que ofrezco, para que los clientes puedan encontrarlos. |
| HU04 | Cliente | Como cliente, quiero buscar y filtrar prestadores y servicios, para encontrar opciones acordes con mi necesidad, ubicación y preferencias. |
| HU05 | Cliente | Como cliente, quiero publicar un trabajo que necesito realizar, para recibir propuestas de prestadores interesados. |
| HU06 | Prestador de servicios | Como prestador de servicios, quiero consultar trabajos disponibles y enviar propuestas o cotizaciones, para acceder a oportunidades de trabajo. |
| HU07 | Cliente | Como cliente, quiero revisar y comparar las propuestas recibidas, para seleccionar y contratar una opción adecuada. |
| HU08 | Cliente / Prestador | Como cliente o prestador, quiero comunicarme y consultar el estado del trabajo, para coordinar y dar seguimiento al servicio contratado. |
| HU09 | Cliente | Como cliente, quiero realizar o registrar el pago del servicio, para completar el proceso de contratación de forma controlada. |
| HU10 | Cliente | Como cliente, quiero calificar y comentar un servicio finalizado, para registrar mi experiencia y aportar a la reputación del prestador. |
| HU11 | Usuario | Como usuario, quiero consultar mi historial de solicitudes, propuestas y contrataciones, para revisar operaciones anteriores. |
| HU12 | Administrador | Como administrador, quiero gestionar usuarios, categorías, publicaciones, incidencias y reportes, para mantener el control operativo de la plataforma. |

## 3. Agrupación funcional

Las historias de usuario pueden agruparse de acuerdo con las principales capacidades de la plataforma:

### Gestión de usuarios
- HU01 - Registro e inicio de sesión.
- HU02 - Gestión del perfil profesional.

### Gestión de servicios
- HU03 - Publicación y administración de servicios.
- HU04 - Búsqueda y filtrado de servicios y prestadores.

### Gestión de trabajos y propuestas
- HU05 - Publicación de trabajos.
- HU06 - Consulta de trabajos y envío de propuestas.
- HU07 - Comparación y selección de propuestas.

### Contratación y seguimiento
- HU08 - Comunicación y seguimiento del trabajo.
- HU09 - Gestión del pago.
- HU10 - Calificación del servicio.
- HU11 - Consulta del historial.

### Administración
- HU12 - Gestión administrativa de la plataforma.
